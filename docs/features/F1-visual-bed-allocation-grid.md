# F1: Visual Bed Allocation Grid

## Overview
A graphical floor plan interface enabling admissions coordinators to monitor bed availability, view patient status, and reserve beds across hospital wards.

## Implementation Details
- **Frontend**: `hospitalbed.html`
- **Backend Route**: `routes/dashboardRoutes.js`
- **Persistence**: MongoDB `beds` collection with atomic updates.

## Say It Out Loud
> "I developed the visual bed allocation grid to replace chaotic whiteboard tracking in emergency admissions. In `hospitalbed.html` and `dashboardRoutes.js`, triage nurses can view a real-time, cinema-style floor map of all hospital beds across ICU, general, and private wards."
