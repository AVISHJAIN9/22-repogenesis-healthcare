# Frequently Asked Questions: Sachidanand Patient Healthcare Portal

### 1. What is Sachidanand Patient Healthcare Portal?
End-to-end clinical patient healthcare and appointment management portal with MongoDB Atlas.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), Vanilla JS / TailwindCSS.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/22-repogenesis-healthcare/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
