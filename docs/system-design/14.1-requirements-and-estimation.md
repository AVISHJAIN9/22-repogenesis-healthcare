# 14.1 Requirements & Capacity Estimation

## Requirements
- Real-time bed occupancy updates across 500 hospital beds.
- Sub-100ms response time for drug contraindication checks.
- Multi-tenant data isolation.

## Capacity Estimation
- 50 concurrent triage nurses and physicians per hospital branch.
- 5,000 active patient encounters per day.
- Storage growth: ~500MB metadata per month in MongoDB + external object storage for imaging.
