# F3: Surgical Bill & Insurance Estimator

## Overview
Interactive pre-admission cost transparency tool calculating procedure packages, daily ward tariffs, and insurer co-payments.

## Implementation Details
- **Frontend**: `insurance.html`, `script.js`
- **Supported Policies**: TPA integration, cashless claim estimation, out-of-pocket caps.

## Say It Out Loud
> "Hospital billing is notoriously opaque, so I created the surgical bill calculator in `insurance.html`. Patients can select their surgical procedure, expected length of stay, and insurance policy details to get an itemized estimate upfront."
